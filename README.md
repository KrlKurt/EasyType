# Название: MoreSpace
Для кого: Для всех людей, которые хотят освободить место, уменьшив вес фото и видео
Какая проблема:  Фото и видео часто занимают много места
Что делает программа: Принимает на вход фото или видео и сжимает его, уменьшая его объём
3–5 основных функций:  сжатие файлов, сохранение их качества, автоматическое изменение размера
Почему здесь можно использовать Go:  В go есть подходящие библиотеки для сжатия
